# UAT-J006-02 — 未計算/LimitationをPDFで明示する
## Preconditions
未計算ServiceまたはPricing Limitationを含むProject。
## Goal
PDFを完全見積と誤認させない。
## Procedure
PDFを出力して内容を確認する。
## Expected result
未計算項目、完全合計でない旨、適用中Pricing Limitation、過小見積riskが必要に応じて記載される。
## Usability criteria
画面を見ていない第三者でも見積制約を理解できる。
