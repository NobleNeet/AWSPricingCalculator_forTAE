# UAT-J001-01 — 0 Planから最初のPlanを作る
## Preconditions
新規Projectを開く。
## Goal
空状態から最初の構成案を作れる。
## Procedure
1. 初期画面を確認する。2. 「最初の構成案を作る」相当の操作を実行する。
## Expected result
Plan 0件状態が明示され、操作後は空の最初のPlanが1件表示される。まだService料金は表示されない。
## Usability criteria
役割名や比較設定を先に入力させず、最初のPlan作成へ進める。
